Every change to Notosaurus is listed in its changelog, and each version is published on GitHub
with the add-on file to download:

- **[Releases](https://github.com/cchabanois/notosaurus/releases)**: the versions, with their
  notes and the `notosaurus-<version>.ankiaddon` file.
- **[Changelog](https://github.com/cchabanois/notosaurus/blob/main/CHANGELOG.md)**: everything
  that changed, including what is coming in the next version (**Unreleased**).

## Updating Notosaurus

- **Installed from AnkiWeb**: Anki checks for add-on updates when it starts, and offers to install
  them. You can also check in **Tools → Add-ons → Check for Updates**.
- **Installed from a file**: download the new `.ankiaddon` from the
  [latest release](https://github.com/cchabanois/notosaurus/releases/latest) and open it, as for
  the first installation.

Then **restart Anki**. The lessons, the instructions and the settings are kept. When a new version
needs new components, Notosaurus asks again before installing them (a minute or two).
