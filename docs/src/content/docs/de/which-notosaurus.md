---
title: "Welches Notosaurus?"
description: "Die Android-App für sich allein oder die Anki-Erweiterung auf einem Computer: was jede braucht, was sie kostet, wo die Lektionen bleiben."
---

Notosaurus gibt es in zwei Formen. Beide machen dieselben Karten, aus denselben Fotos, mit
denselben Anweisungen und derselben Durchsicht; sie unterscheiden sich darin, wo Notosaurus
läuft und wer die KI bezahlt.

- **Die Android-App**: alles auf dem Handy. Kein Computer, kein KI-Schlüssel: Ein Abo bezahlt
  die KI.
- **Die Anki-Erweiterung**: Notosaurus läuft auf dem Computer, in Anki, und du benutzt es vom
  Handy aus im selben WLAN. Kostenlos, mit deinem eigenen Schlüssel für einen KI-Dienst.

| | Android-App | Anki-Erweiterung |
|---|---|---|
| **Was du brauchst** | Ein Android-Handy, AnkiDroid | Einen Computer mit Anki, ein Handy im selben WLAN (Android oder iPhone) |
| **iPhone** | Nein: nur Android | Ja: die Seite in Safari, gelernt wird in AnkiMobile |
| **Die KI** | Gemini von Google, über den Notosaurus-Dienst | Der Dienst deiner Wahl: Gemini, Claude, OpenAI, OpenRouter oder ein Modell zu Hause |
| **Was es kostet** | Ein Abo über Google Play, nach einer kostenlosen Testphase | Kostenlos; der KI-Dienst rechnet direkt mit dir ab, von einem Bruchteil eines Cents bis zu ein paar Cent pro Lektion |
| **Die Lektionen** | Bleiben auf dem Handy | Bleiben auf dem Computer |
| **Die Karten** | Direkt in AnkiDroid | In Anki am Computer, dann über AnkiWeb auf die Handys; oder als `.apkg`-Datei |
| **Mehrere Kinder** | Ein Eintrag pro Kind | Ein Eintrag pro Kind, auf Wunsch ein Anki-Benutzerprofil pro Kind |

Beides zugleich? Die App kann auch **mit deinem Computer** arbeiten: Sie zeigt dann die Seite
der Erweiterung, und die Lektionen, die KI und die Karten bleiben auf dem Computer, kostenlos.
