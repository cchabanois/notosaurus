---
title: "Quale Notosaurus?"
description: "L'app Android da sola, o l'add-on di Anki su un computer: cosa serve a ciascuno, quanto costa, dove restano le lezioni."
---

Notosaurus esiste in due forme. Entrambe fanno le stesse carte, dalle stesse foto, con le stesse
istruzioni e la stessa revisione; cambiano dove gira Notosaurus e chi paga l'IA.

- **L'app Android**: tutto sul telefono. Niente computer, niente chiave IA: un abbonamento paga
  l'IA.
- **L'add-on di Anki**: Notosaurus gira sul computer, dentro Anki, e lo usi dal telefono sulla
  stessa rete Wi-Fi. Gratis, con la tua chiave per un servizio di IA.

| | App Android | Add-on di Anki |
|---|---|---|
| **Cosa ti serve** | Un telefono Android, AnkiDroid | Un computer con Anki, un telefono sulla stessa Wi-Fi (Android o iPhone) |
| **iPhone** | No: solo Android | Sì: la pagina in Safari, le carte ripassate in AnkiMobile |
| **L'IA** | Gemini di Google, tramite il servizio Notosaurus | Il servizio che scegli: Gemini, Claude, OpenAI, OpenRouter o un modello a casa |
| **Quanto costa** | Un abbonamento tramite Google Play, dopo una prova gratuita | Gratis; il servizio di IA ti fattura direttamente, da una frazione di centesimo a qualche centesimo per lezione |
| **Le lezioni** | Restano sul telefono | Restano sul computer |
| **Le carte** | Dritte in AnkiDroid | In Anki sul computer, poi sui telefoni tramite AnkiWeb; oppure come file `.apkg` |
| **Più figli** | Una scheda per figlio | Una scheda per figlio, e un profilo Anki per figlio se vuoi |

Tutti e due insieme? L'app può anche funzionare **con il tuo computer**: mostra allora la pagina
dell'add-on, e le lezioni, l'IA e le carte restano sul computer, gratis.
