		olvidado de los colores».
	</Card>
	<Card title="Esquemas, fórmulas, figuras" icon="puzzle">

		geometría exactas, textos con huecos y preguntas de opción múltiple.
	</Card>
	<Card title="Directo a Anki, listo para el examen" icon="rocket">

		<a href="tests/">Reúne sus lecciones</a> y repásalas juntas.
	</Card>
	<Card title="Pensado para las familias" icon="star">

		nombre nunca llega a la IA.
	</Card>
	<Card title="En el móvil o en el ordenador" icon="github">

		OpenRouter o un modelo en casa).
	</Card>
