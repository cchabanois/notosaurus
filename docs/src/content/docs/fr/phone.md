title: "Sur le téléphone"
description: "Ouvrir Notosaurus sur le téléphone avec le QR code, et l'ajouter à l'écran d'accueil sur Android et iPhone."
---

Avec le greffon Anki sur l'ordinateur, le téléphone ouvre Notosaurus dans son navigateur : une
page web, sur le même Wi-Fi. Ajoutée à l'écran d'accueil, elle s'ouvre ensuite d'un geste, comme
une appli.

:::tip[Sur Android, l'application]
Sur Android, l'[application Notosaurus](../android-app/) peut le faire aussi : dans son mode
**💻 Sur mon ordinateur**, elle affiche la page de l'ordinateur, sans navigateur. Ou, en
**📱 Sur ce téléphone**, elle fait les cartes toute seule, sans l'ordinateur.
:::

## 1. Ouvrir Notosaurus

Dans Anki sur l'ordinateur, **Outils → Notosaurus → Ouvrir sur le téléphone…** affiche un QR code.
Avec le téléphone sur le **même Wi-Fi** que l'ordinateur, scannez-le avec l'appareil photo du
téléphone et ouvrez le lien.

Scanner le QR code **autorise aussi ce téléphone** à utiliser Notosaurus : les autres appareils du
Wi-Fi ne le peuvent pas (voir
[Confidentialité et sécurité sur l'ordinateur](../privacy/#qui-peut-utiliser-notosaurus-)).

## 2. L'ajouter à l'écran d'accueil

Faites-le **juste après avoir scanné le QR code**, depuis la page qui s'est ouverte : l'icône garde
l'autorisation du téléphone.

### Android

Dans **Chrome** :

1. Le menu **⋮**, en haut à droite → **Ajouter à l'écran d'accueil**.

   ![Le menu de Chrome : Ajouter à l'écran d'accueil](../../../assets/screenshots/fr/android-menu.png)

2. **Créer un raccourci** : gardez le nom **Notosaurus**, puis **Ajouter**.

   ![Créer un raccourci](../../../assets/screenshots/fr/android-shortcut.png)

3. **Ajouter à l'écran d'accueil** (ou appuyez longuement sur l'icône pour la placer vous-même).

   ![Ajouter à l'écran d'accueil](../../../assets/screenshots/fr/android-place.png)

4. L'icône **Notosaurus** est sur l'écran d'accueil, parfois sur la page suivante.

   ![L'icône Notosaurus sur l'écran d'accueil](../../../assets/screenshots/fr/android-home.png)

Dans les autres navigateurs :

- **Samsung Internet** : le menu **≡** → **Ajouter la page à** → **Écran d'accueil**.
- **Firefox** : le menu **⋮** → **Ajouter à l'écran d'accueil** (ou **Installer**).

### iPhone et iPad

Dans **Safari** : le bouton **Partager** (le carré avec une flèche) → **Sur l'écran d'accueil** →
**Ajouter**. Sur un iPhone, l'icône ne partage pas la mémoire de Safari : c'est en l'ajoutant juste
après avoir scanné le QR code qu'elle est autorisée.

## Bon à savoir

- **Le téléphone doit être sur le même Wi-Fi** que l'ordinateur, et Anki doit être ouvert sur
  l'ordinateur (avec le greffon) : Notosaurus fonctionne à la maison, pas à l'extérieur.
- **Si tous les téléphones ont été déconnectés** (Réglages → Téléphones) ou si l'adresse de
  l'ordinateur a changé (après un redémarrage de la box), l'icône n'ouvre plus Notosaurus : scannez à
  nouveau le QR code, puis ajoutez de nouveau la page à l'écran d'accueil (et supprimez
  l'ancienne icône).
