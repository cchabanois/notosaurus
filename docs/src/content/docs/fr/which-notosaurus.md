---
title: "Quel Notosaurus ?"
description: "L'application Android toute seule, ou le greffon Anki sur un ordinateur : ce qu'il faut pour chacun, ce que ça coûte, où sont gardées les leçons."
---

Notosaurus existe sous deux formes. Les deux font les mêmes cartes, à partir des mêmes photos,
avec les mêmes consignes et la même relecture ; elles diffèrent par l'endroit où Notosaurus
tourne et par qui paie l'IA.

- **L'application Android** : tout sur le téléphone. Pas d'ordinateur, pas de clé d'IA : un
  abonnement paie l'IA.
- **Le greffon Anki** : Notosaurus tourne sur l'ordinateur, dans Anki, et vous l'utilisez depuis le
  téléphone, sur le même Wi-Fi. Gratuit, avec votre propre clé pour un service d'IA.

| | Application Android | Greffon Anki |
|---|---|---|
| **Ce qu'il faut** | Un téléphone Android, AnkiDroid | Un ordinateur avec Anki, un téléphone sur le même Wi-Fi (Android ou iPhone) |
| **L'IA** | Gemini de Google, par le service Notosaurus | Le service de votre choix : Gemini, Claude, OpenAI, OpenRouter, ou un modèle à la maison |
| **Ce que ça coûte** | Un abonnement par Google Play, après un essai gratuit | Gratuit ; le service d'IA vous facture directement, d'une fraction de centime à quelques centimes par leçon |
| **Les leçons** | Gardées sur le téléphone | Gardées sur l'ordinateur |
| **Les cartes** | Directement dans AnkiDroid | Dans Anki sur l'ordinateur, puis sur les téléphones par AnkiWeb ; ou en fichier `.apkg` |
| **Plusieurs enfants** | Une fiche par enfant | Une fiche par enfant, et un profil Anki par enfant si vous le souhaitez |

Les deux à la fois ? L'application peut aussi fonctionner **avec votre ordinateur** : elle montre
alors la page du greffon, et les leçons, l'IA et les cartes restent sur l'ordinateur,
gratuitement.
