Voir [Dépannage du greffon](../troubleshooting/) ou [Dépannage de l'application](../app-troubleshooting/).

## Questions

**L'application ou le greffon ?**
L'[application Android](../android-app/) fonctionne seule sur le téléphone, avec un abonnement ; le
greffon tourne sur l'ordinateur, gratuitement, avec votre propre clé pour un service d'IA. Voir
[Quel Notosaurus ?](../which-notosaurus/).

**Notosaurus marche-t-il sans Anki sur ordinateur ?**
Oui, avec l'[application Android](../android-app/) : elle fait les cartes sur le téléphone et les
met dans AnkiDroid. Le greffon a besoin d'Anki sur un ordinateur ; Notosaurus peut aussi tourner
[en autonome](../install/). Le navigateur du téléphone a toujours besoin de l'ordinateur (ou d'un
serveur) où tourne Notosaurus.

**Est-ce que ça marche sur iPhone ?**
Oui, dans le navigateur, avec Notosaurus sur l'ordinateur (il n'y a pas d'application iPhone) : la page s'ouvre dans Safari et peut être ajoutée à l'écran d'accueil. Les révisions se font
dans AnkiMobile (payant, il finance le développement d'Anki).

**Plusieurs enfants peuvent-ils l'utiliser ?**
Oui : chaque enfant a sa fiche (le bouton **Enfants**, 🧒, sur la page principale), avec sa classe, ses paquets, ses
instructions et ses leçons. Voir [Plusieurs enfants](../several-children/).

**Combien ça coûte ?**
Le greffon est gratuit : vous payez directement le service d'IA, d'une fraction de centime à
quelques centimes par leçon (voir [Réglages et services d'IA](../ai-services/)).
L'[application Android](../android-app/) seule fonctionne avec un abonnement, après un essai
gratuit de 14 jours (voir [L'abonnement](../app-subscription/)) ; avec le greffon, elle est gratuite.

**Comment soutenir Notosaurus ?**
Si Notosaurus vous rend service, vous pouvez faire un don sur
[Ko-fi](https://ko-fi.com/notosaurus) : **☕ Soutenir Notosaurus** en bas de la page et des
réglages, ou **Outils → Notosaurus → Soutenir Notosaurus…** dans Anki (sur l'ordinateur : l'application n'en a pas, son
abonnement paie). Notosaurus reste gratuit, sans publicité.

**Une carte est fausse : comment vous le dire ?**
Dans l'application Android, **⋯ → ⚑ Signaler** sur la carte : cela envoie la carte telle que vous
la voyez, avec votre commentaire, jamais les photos de la leçon ni le prénom de l'enfant. Chaque
signalement est lu. Voir [Signaler un problème](../review/#signaler-un-problème).

**Quelque chose ne marche pas : comment signaler un bug ?**
Sur GitHub, avec le [formulaire Bug](https://github.com/cchabanois/notosaurus/issues/new?template=bug.yml) (il faut un compte GitHub, gratuit) : il demande où
cela se produit, la version et les étapes. L'issue est publique : n'y joignez jamais la photo d'un
cahier, ni le prénom d'un enfant. Une carte fausse faite par l'IA, dans l'application Android :
**⋯ → ⚑ Signaler** dessus est plus rapide.
