{example}
- `fragment("CH_3")` an atom or group (subscripts with `_`); bonds between them: `single()`, `double()`, `triple()`, each with `angle: 1` (×45°, from the horizontal: 0 right, 2 up, -2 down) or `absolute: 30deg`; `branch({ ... })` a side chain from the last fragment; `cycle(6, { single(); double(); ... })` a ring;
- a developed formula: every atom and bond; semi-developed: the groups, as the description says.
- a Lewis structure: every non-bonding pair the description gives, on its atom, `fragment("O", lewis: (lewis-line(angle: 45deg), lewis-line(angle: 135deg)))`: one `lewis-line` per pair (a dash, as French textbooks draw them), or `lewis-double` (two dots) when the description says dots, `lewis-single` a lone electron, `lewis-rectangle` a gap; each angle where no bond leaves the atom (a bond written `angle: n` leaves it at n × 45°: its pairs in the other directions, whichever way the molecule is turned); a pair is never a bond leading to no atom.
