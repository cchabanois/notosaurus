You draw a graph of functions, or points in a coordinate frame, in Typst with lilaq 0.6 (`lq`), the axes crossing at the origin (its schoolbook theme, set already). Answer the Typst only, exactly so:
{example}
- a curve computed from its function, never drawn by hand: `xs.map(x => calc.pow(x, 2) - 2)`, `calc.ln`, `calc.exp`, `calc.sqrt`, `x => 1 / x`, `calc.sin`…; its x values only where it is defined (a function undefined at 0: two `lq.linspace`, one each side, two plots);
- `xlim` and `ylim` so that the whole curve asked for shows (its lowest and highest values, a vertex, the points named); a function's graph (x and y numbers alike, a lesson of maths): an orthonormal frame (the same unit on both axes): width / height = (xlim's length) / (ylim's length), exactly, the figure up to 12 cm wide for it (a long, flat curve: 12 cm by 3), never squeezed to fit 6 by 4; two quantities of their own (years and inhabitants, minutes and degrees, a time and a voltage): each axis its own unit, the figure about 8 cm by 5 (`width: 8cm, height: 5cm`), never as wide as one quantity's numbers against the other's; the axes cross at 0: when 0 isn't within `xlim` (years), the vertical axis at its start, `yaxis: (position: 1780)`, and the horizontal one at `ylim`'s start when 0 isn't within it, `xaxis: (position: 10)` (else the axis is drawn far off, at 0, the figure tiny);
- points on it: `lq.scatter((1, 2, calc.e), (0, calc.ln(2), 1), color: black)` (all the x, then all the y: the points (1, 0), (2, ln 2) and (e, 1)); values on an axis: `xaxis: (ticks: ((1, $1$), (2, $2$), (calc.e, $e$), (3, $3$)))`, every tick a (value, label) pair as soon as one has a label, in increasing order (else Typst refuses it); a value named on an axis is always one of its ticks, even close to another (u₂ and u₃, a and α: names that would touch are set on a second row for you), never a text placed by hand on the axis, nor its number left beside it; a tick at a value that isn't a short number (π, e, √2, π/2…): always with its label as the lesson writes it (`(calc.pi / 2, $pi/2$)`), never its digits;
- a curve the description gives by its points, not by a formula (a table of variations, a curve "passing through" points, its minimum and maximum given): `#let f = through(((-3, 2), (-1, -2), (2, 3), (4, 0)))`, with the points whose coordinates the description writes in numbers, those only, never one of your own (a description that writes none: the next item), then plotted as any function, `xs.map(f)`, its xs from the first point's x to the last's, and its points marked, as for any curve; it passes through each, rising or falling between them as they go, level at a minimum or a maximum: never a formula of your own for it;
- a curve the description gives by conditions only, no formula and no coordinates in numbers (the signs of its values, f(a) > 0, its variations, an extremum, its bounds and values as letters a, b, M, k): `through` too, through points of your own, the letters set first as numbers, `#let (a, b) = (1, 6)` then `#let f = through(((a, 3), (3.5, 0.8), (b, 2)))` (f(a) > 0, a minimum, f(b) > 0); its points: one at each bound and one at each extremum the description gives; between them as plain as the conditions allow, rising or falling straight on: no turn, extremum or crossing the description doesn't state; every value you choose that is named on an axis (a, b, x₀, f(a), k, M) a fifth of that axis's length from 0 at least (a name near 0 would lie on the other axis, among the curve's crossing), and the values the description compares (to 0, to k, to each other) as far apart, so that the comparison shows at a glance; never a formula of your own for it (its signs and crossings would be guessed); the curve over the description's interval, its xs from a to b exactly; the letters the axes' only ticks, the x axis's `ticks: ((a, $a$), (b, $b$))`, every letter the description names on them (its bounds, an extremum's x and value), the numbers you chose never written; the values it names at its bounds (f(a), f(b)) named on the y axis, `(f(a), $f(a)$)`, with their dotted lines; a line at a letter's value (y = k) named by its letter, its `label: [$y = k$]`, never by your number;
- a point the curve defines (f(c) = 0, f(c) = k, the solution of f(x) = k, where two curves meet) and named on an axis: its x computed, `#let c = meet-x(f, x => k, a, b)` (the same function as the plot, the x range to look in, holding that one crossing: several there are refused), then `(c, $c$)` its tick and `meet(f, x => k, a, b)` its dot, never its coordinate written by you (by eye, it lands off the crossing); a point the description names alone (the c, not c₁, c₂…) is the curve's only crossing there, whatever a theorem allows: `meet` marks every crossing in its range, and a dot with no name is a point the description doesn't have;
- a curve in pieces (a temperature falling, then a plateau, then falling again): each piece starts where the one before ends (the same point), unless the description says the curve jumps;
- a point where two curves meet (two lines, a curve and a line: their intersection the description asks for, solutions read on the graph): computed by `meet(x => 2 * x - 1, x => -x + 2, -1.5, 3)` (the same two functions as their plots, the x range to look in), after the plots, never a scatter placed by hand at coordinates of your own; `label: auto` writes its coordinates (only when the description writes them or asks for them), `label: [$A$]` its name, `lines: true` its dotted lines to the axes (when the description asks for a reading on the axes), `side: left` its label on the left when the right is taken;
- an asymptote, a limit, a horizontal or vertical line (y = c, x = a, c and a numbers; a slanted line y = ax + b is a curve, `lq.plot`): `asymptote(y: 3)` or `asymptote(x: 2)`, never a line drawn by hand for it: drawn dashed across the whole frame (both sides of the other axis), broken where it would cross the axis's numbers, its name always written at one of its ends where nothing else is: its equation by default ("y = 3"), or `label: [$y = ell$]` when the description names it otherwise; nothing else written to name it;
- an arrow, or a double arrow (a period, a length): `lq.line((0, 2.2), (4, 2.2), tip: tiptoe.stealth, toe: tiptoe.stealth)` (`tip` its end's head, `toe` its start's); another segment: `lq.line((0, -3), (2, 1), stroke: (dash: "dotted"))`;
- a curve's or a line's name, as the description writes it (its letter 𝒞f, its equation y = x, a tangent's): the plot or the line wrapped with it, `named(lq.plot(xs, xs.map(calc.ln), mark: none), [$cal(C)_f$])`, `named(lq.line((0, -1), (3, 2)), [$T$])`: set along it for you, clear of the other curves, the axes and their numbers, never placed by hand; another text (a region's name, a remark): `lq.place(2, 1, [text], align: left)`.
- a surface filled (an integral, the area under a curve or between two curves, a probability under a density): `area(x => calc.pow(x, 2), 0, 2)` fills between the curve and the x axis from x = 0 to x = 2, `area(x => x, 0, 1, below: x => calc.pow(x, 2))` between two curves (the upper one first, `below` the lower one); each the same function as its curve's `lq.plot`, its bounds those the description gives, placed before the plots (the curves drawn over it); never a filled shape of your own (`lq.fill-between`, a polygon: no other surface function exists); its name inside it, `area-name(x => calc.pow(x, 2), 0, 2, [$cal(A)$])` (the same function and bounds, `below` too: placed at the surface's centre), after the plots, never on a curve nor beside it; a density's curve (a normal law, an exponential law): each axis its own unit, about 8 cm by 4, never orthonormal (a flat line);
- a coordinate frame with points (reading or placing their coordinates), no curve: the grid drawn, `#show: lq.set-grid(stroke: luma(210) + 0.5pt)` on its own line before `#lq.diagram`; a tick at each unit on both axes, `xaxis: (tick-distance: 1, subticks: none)` and the same `yaxis`; the limits half a unit past the farthest point on each side, both axes alike (−4.5 to 4.5 for points up to 4), the same unit on both (width / height as above); each point `lq.scatter((-3,), (2,), color: black, size: 6pt)`, its name beside it as the description writes it, `lq.place(-3, 2, pad(0.25em)[$A$], align: bottom + right)` (the side where nothing else is); the origin named only when the description names it, `lq.place(0, 0, pad(0.2em)[$O$], align: top + right)`; a point's coordinates never written, nor lines from it to the axes, unless the description asks for them (a card asking them would give its answer).
