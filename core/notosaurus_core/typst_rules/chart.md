You draw a statistics chart in Typst with the chart function given (cetz): its bars' heights and its sectors' angles are computed from the counts, a line's axes and graduations from its measures, box plots' boxes and axis from their values. Answer the Typst only, exactly so:
{example}
- `kind`: `"bars"` for a bar chart (diagramme en bâtons), `"pie"` for a pie chart (diagramme circulaire), `"semi"` for a half pie (diagramme semi-circulaire), `"line"` for measures joined by a line (a heart rate over time, a temperature over the months), `"histogram"` and `"scatter"` as said below;
- `values`: each value's label and its count, `("Chat", 12)`, as the description gives them, in its order; never an angle, a percentage or a height of your own: the chart computes them;
- `horizontal: true` when the description asks for horizontal bars (barres horizontales, bars lying): their names one under the other, the first at the top; else bars standing;
- a bar chart's or a pie's values are written on it by default, as the description gives them (they are what it shows): `unit: "%"` when they are percentages (`"€"`, `"km"`… their unit as the description writes it), never one of your own; `written: ()` only when the description gives no value at all (only the parts: the counts you give then just draw them); `hidden: ("Pétrole",)` the labels whose value the card's question asks for (a count, a share, a frequency, an angle), written "?", their number never shown; `degrees: true` writes a sector's angle with its count, only when the description asks for it;
- `axis`: the bars' axis title as the description writes it (`axis: "Effectif"`); `step` only when it gives the graduation (`step: 5`), else every unit up to 12, then 2, 5, 10… (values with decimals, a probability law: by tenths, hundredths…, computed)
- a line: `values` its measures as `(x, y)` numbers, `((0, 70), (2, 72), (4, 120))`, as the description gives them; `axes: ("Temps (min)", "Battements / min")`, the x title then the y title, their units with them; `written` the x whose measure is written (`written: (4,)`), none unless the description says it, `hidden: (4,)` an x whose measure the card asks for ("?"); `step: (2, 10)` only when it gives both graduations, or when the measures differ only after their first decimal and those differences are what the figure shows (a calibration line, each measure read on the axis): then the x step and a round y step that tells the measures apart (0,01, 0,02, 0,05: `step: (50, 0.01)` for 1,000, 1,019, 1,038…), never the gap between two measures nor a measure itself as a step, as without it the y axis is never graduated finer than a tenth, so that a measure which barely changes never looks as if it changed much; `reversed: true` when the description's x axis runs from its largest value to its smallest (an infrared spectrum, its wavenumbers from 4000 to 500 cm⁻¹), the values still given as they are; never a function, a range or a graduation of your own: the chart starts its axes where the measures are.
- a line's measures are only those the description gives, at the x it gives them: never a point of your own between or around them to round the line off (a peak given alone is one point); when it gives a change in words without a number (rises, stays flat, falls back), only the points that change needs, at the x it says;
- `smooth: true` when the description asks for a curve through its measures (une courbe, the curve of…): drawn through every measure, never above nor below them between two; else the measures joined by straight lines; never a function of your own to round them off;
- `numbered: false` when the description gives no value at all for the y axis (only how it varies): the line then shows its shape, its y values only placing it, never read;
- `marks: ((6, "arrêt"),)` an event at an x the description names (a moment, a date): a dashed line across, its label under the axis; `spans: ((2, 4, "effort"),)` a stretch of x it names, shaded; their labels as the description writes them;
- on standing bars (a probability law, a distribution): `marks: ((10, $E(X) = 10$),)` a value marked (the expectation, the mean: a dashed line through that bar, its label over the chart), `spans: ((7, 13, $]6 ; 14[$),)` an interval of values shaded behind its bars (from its first bar to its last, as the description bounds it: an open interval's bars inside it only), each by its bars' names as `values` writes them; never a line of points nor a chart of your own for them;
- several lines of the same measure (the same quantity in the same unit, measured on several groups, subjects or places, compared): `values: (("Groupe A", ((0, 0.5), (1, 0.6))), ("Groupe B", ((0, 0.5), (1, 0.48))))`, each line with its name as the description writes it and its own measures, on one axis (their values compared on the same graduation), a legend naming them; never `second` for them;
- a second measure of another quantity, with another unit, over the same x (two curves the description gives together; never a climate chart's precipitation and temperature): `second: (values: ((x, y), …), axis: "Pression (hPa)")`, on its own axis at the right, never left out nor drawn as a second chart.
- a climate chart (diagramme ombrothermique, climogramme: a place's precipitation and temperature month by month): `kind: "climate"`, `values: (("J", 45, 5), ("F", 40, 6))`, each month as the description names it (its initial or its short name), its precipitation (mm) then its mean temperature (°C), as the description gives them, in its order; `axes: ("Précipitations (mm)", "Température (°C)")`, the precipitation's title then the temperature's, as the description writes them; the chart draws the precipitation as bars and the temperature as a curve, each on its own axis, their scales tied (P = 2T) and computed: never `"bars"` with a `second`, nor two lines;
- a histogram (histogramme: values grouped in classes, [150 ; 155[, [155 ; 160[…): `kind: "histogram"`, `values: ((150, 155, 6), (155, 160, 12), (160, 165, 17))`, each class its lower bound, its upper bound and its count, as the description gives them, in order; `axis` the counts' title (`axis: "Effectif"`), `axes: ("Taille (cm)", none)` the classes' title with their unit; the chart draws the rectangles side by side, each as wide as its class (unequal classes: each one's area its count), every bound under the axis, the counts written on them (`written`, `hidden` by a class's lower bound); never bars (`"bars"`) for classes of values, nor a class as a label;
- a scatter plot (nuage de points: a series of two variables, a point per individual): `kind: "scatter"`, `values: ((1, 8), (2, 9), (3, 11))` the points as `(x, y)`, as the description gives them; `axes` the two titles, their units with them; `fit: (1.4, 6.5)` the fitted line y = ax + b when the description gives it (drawn across the points and named), never one of your own; the points never joined: never `"line"` for a cloud of points;
- box plots (boîtes à moustaches): `kind: "box"`, `values: (("Classe A", (5, 9, 11, 14, 18)), ("Classe B", (2, 8, 12, 16, 20)))`, each box's name as the description writes it and its five values in this order, minimum, first quartile, median, third quartile, maximum, the boxes in the description's order (the first at the top), all on one shared axis; one box alone, which the description doesn't name: its five values only, `values: (4, 9, 12, 15, 19)`; `limits: (0, 20)` the axis's first and last values when the description gives them; `step` only when it gives the graduation; `axis` the axis's title when it gives one; `written` the boxes whose five values are written (`"all"` or their names), none unless the description says them written; never a canvas, a box, a scale or a graduation of your own: the chart sizes the axis and graduates it.
- a pyramid (a population pyramid, an age pyramid: two series compared class by class, back to back): `kind: "pyramid"`, `classes: ("0-9 ans", "10-19 ans", "20 ans et plus")` the classes as the description names them, the youngest (the lowest) first, drawn from the bottom up; `values: (("Hommes", (17, 12, 8)), ("Femmes", (16.5, 11.5, 8)))` the two series, the one the description puts at the left first, each its name as the description writes it and one value per class in the classes' order, each side's value as a positive number; `axis` the values' title with their unit as the description gives it (`axis: "% de la population"`, `axis: "milliers d'habitants"`); `step` only when it gives the graduation; `written` the classes whose two values are written (`"all"` or classes), none unless the description says them written; the chart draws the bars back to back, the classes between them, the two sides' graduation alike, from 0 at the centre: never two charts, a bar per series one under the other, nor bars of your own;
- a pyramid whose description gives no value (only its shape: a wide base, a narrow top, a bulge): `numbered: false`, its values only drawing the shape the description states, nothing else: lengths from 1 to 10, changing evenly from class to class between the places it names (a narrow base and a wide top: from the shortest at the bottom to the longest at the top), the two sides the same unless it says how they differ; never the shape you know of that population (its real figures, a bulge, a side longer than the other) where the description says none; never written, no `axis` nor `step`: the chart shows the shape without any number, never a figure of your own read as data.
