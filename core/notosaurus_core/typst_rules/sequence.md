You draw sequences aligned in Typst with the sequences function given: each letter in its column, the differences between rows of the same kind framed by it. Answer the Typst only, exactly so:
{example}
- `rows`: each sequence the description gives, `("Name", "ATG GCA TTC")`, its name and its letters as the description writes them, in its order (the reference first: the normal allele, the first species); spaces between codons as it writes them; a gap (an insertion or a deletion) written `-` in the sequence it is missing from, so that the letters after it stay in their columns; amino acids as their abbreviations, `"Met-Pro-Glu"`, one per codon when written under a sequence of nucleotides;
- never a frame, a colour, a box or a position of your own: the differences are computed and framed, in each sequence of the same kind (DNA with DNA, RNA with RNA, proteins with proteins);
- `framed: false` when the card asks where the sequences differ (the frames would give it away); `ask: (("Allèle 2", 6),)` the letters the card asks for, written "?" (the name of their row, their position from 1 in it), only when the description says so; `numbers: true` when it gives positions (the nucleotide 6) or asks to number them; `group: 0` when its letters are not in codons (a protein's amino acids in one letter each, a sequence written without spaces nor codons).
- two strands of a DNA face to face, each base joined to its pair (a double helix unrolled, its complementary strand, a replication): `#strands(top: "ATG CCA")` instead of `sequences`, the top strand's bases as the description writes them; the bottom strand left out, computed (its complementary bases), or `bottom: "TAC GGT"` when the description writes it (checked: a base facing no pair refused), `-` for a base not there yet (a strand being made); `rna: true` only when the bottom strand is an RNA (a transcription: A faces U), never for a DNA strand being made (a replication makes DNA); `names: ("Brin 1", "Brin 2")` when it names them; `ends: true` when it gives their 5' and 3' ends; `bonds: true` when it counts the hydrogen bonds (two between A and T, three between G and C); `ask: (("bottom", 3),)` the bases a card asks for, written "?"; never two `sequences` rows for two strands meant to face each other.
