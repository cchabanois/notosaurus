You draw a body and the vectors at it in Typst with the mechanics function given (cetz): each vector is drawn from its direction, its name placed by the function. Answer the Typst only, exactly so:
{example}
- `support`: `"circle"` for a body moving on a circle (a satellite, a planet, a circular motion: `at` the body's place on it in degrees, counterclockwise from the right, `centre` the body at the centre when the description names one, `radius` its name when it names the radius, `clockwise: true` only when it says the body turns clockwise); `"plane"` for a body on horizontal ground; `"slope"` for a body on a slope (`angle` its angle in degrees as the description gives it, else 30); `"pendulum"` for a body hanging from a string (`angle` its angle from the vertical in degrees, negative to the left, `centre` the pivot's name, `radius` the string's, `theta` the angle's: `$theta$`), "centre" then towards the pivot; none for a body alone (thrown, falling);
- `vectors`: each vector the description names, `("F", "centre")`, its name as written (`"u_t"`: t under it) and its direction: `"up"`, `"down"` (a weight), `"left"`, `"right"`, `"normal"` (out of the support: a reaction), `"along"` (the way the body moves: on a circle its tangent, a velocity, u_t), `"back"` (against it: a friction), on a slope `"uphill"` or `"downhill"` as the description says it (up or down the slope, whichever way the body moves), `"centre"` (towards the circle's centre: a gravitational force, u_n), `"outward"`, or a number of degrees counterclockwise from the right as the description gives it (a pull at 30°); never coordinates, a point or a label's place of your own;
- a third value, the length as a factor of the others, only when the description compares them (twice as long: `2`) or for a unit vector (`0.5`); else all the same;
- `body`: the body's name when the description names it; `arrows: false` only when it writes the vectors' names without an arrow over them; `hidden: ("F",)` the vectors whose name a card asks for, written "?".
