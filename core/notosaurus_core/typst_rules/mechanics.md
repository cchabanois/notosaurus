You draw a body and the vectors at it in Typst with the mechanics function given (cetz): each vector is drawn from its direction, its name placed by the function. Answer the Typst only, exactly so:
{example}
- `support`: `"circle"` for a body moving on a circle (a satellite, a planet, a circular motion: `at` the body's place on it in degrees, counterclockwise from the right, `centre` the body at the centre when the description names one, `radius` its name when it names the radius, `clockwise: true` only when it says the body turns clockwise); `"plane"` for a body on horizontal ground; `"slope"` for a body on a slope (`angle` its angle in degrees as the description gives it, else 30); `"pendulum"` for a body hanging from a string (`angle` its angle from the vertical in degrees, negative to the left, `centre` the pivot's name, `radius` the string's, `theta` the angle's: `$theta$`), "centre" then towards the pivot; `"liquid"` for a body immersed in a liquid (in a container); none for a body alone (thrown, falling, hanging);
- the scene the description gives, never left out: `string: true` the body hanging from a string or a dynamometer (above it); `other` the second body when two bodies act on each other (the Earth and the Moon, a magnet and a nail: `body` the first, `others` the vectors at the second, `"towards"` or `"away"` the other body, `distance` its name when the description names the distance); `shape: "ball"` for a round body on the ground (a ball), `"block"` for two bodies drawn as blocks (a magnet, a nail); `body` the body's name, or its point's when the description names one (G, M); on a circle `centre` a body (Terre) or a point (O);
- `marked: ("F",)` the vectors whose angle with the ground or the slope the description marks (its value computed), `marked: (F: $alpha$)` when it names it; `path: ([A], [B], [5 m])` the body's displacement on the ground from A to B and its length, when the description gives it;
- `scale: (2, "N")` when the description draws to a scale (1 cm for 2 N), each vector's third value then its value in that unit (`("P", "down", 5)`), never a length of your own;
- `vectors`: each vector the description names, `("F", "centre")`, its name as written (`"u_t"`: t under it, `"F_(T/L)"`: T/L under it, `"Pi"`: Π) and its direction: `"up"`, `"down"` (a weight), `"left"`, `"right"`, `"normal"` (out of the support: a reaction), `"along"` (the way the body moves: on a circle its tangent, a velocity, u_t), `"back"` (against it: a friction), on a slope `"uphill"` or `"downhill"` as the description says it (up or down the slope, whichever way the body moves), `"centre"` (towards the circle's centre: a gravitational force, u_n), `"outward"`, or a number of degrees counterclockwise from the right as the description gives it (a pull at 30°); never coordinates, a point or a label's place of your own;
- without a scale, a third value, the length as a factor of the others, only when the description compares them (twice as long: `2`) or for a unit vector (`0.5`); else all the same;
- `body`: the body's name when the description names it; `arrows: false` only when it writes the vectors' names without an arrow over them; `hidden: ("F",)` the vectors whose name a card asks for, written "?".
