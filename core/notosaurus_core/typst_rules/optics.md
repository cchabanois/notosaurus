You draw light's rays in Typst with the optics functions given (cetz): the rays, their angles and the image are computed from the values you give, never placed by you. Answer the Typst only, exactly so:
{example}
- refraction or reflection of a ray at the surface between two media: `#refraction(n1: …, n2: …, incidence: …, media: (…, …))`: `n1` the index of the medium the light comes from (drawn above), `n2` the other's (below), as numbers with a point (`1.33`); `incidence` the angle of incidence in degrees, from the normal, as the description gives it; `media` the two media's names as the description writes them, the light's first (with their index when it gives it: `[Eau ($n_2 = 1,33$)]`), else leave it out; `mirror: true` for a plane mirror (the light reflected only, `n1`, `n2` left out, `media` its medium alone); `reflected: true` when it asks for the reflected ray or its angle (beyond the critical angle the reflection is total: its ray drawn by itself, never a refracted ray; its angle named only with `reflected: true`); `names: (i1: $i_1$, i2: $i_2$, r: $r$)` the angles' names as the description writes them; `values: true` only when it asks the angles' values written (computed, never written by you); `point: [I]` the point of incidence's name when it names it; `hidden: ("i2",)` the angles whose name a card asks for, written "?";
- the image of an object by a converging lens: `#lens(focal: 4, object: -6, height: 2)`: `focal` its focal length f' (positive), `object` the object's place OA as an algebraic value (before the lens: negative, OA = −6 cm: `-6`), `height` the object's height AB, all in the description's unit (cm unless it says otherwise, `unit: "mm"`); the image A'B', real or virtual, and the three rays from B (through O, parallel then through F', through F then parallel) computed and drawn to it; `distances: true` when it asks OA and OA' marked; `names: (A: $A$, B: $B$, A2: $A'$, B2: $B'$, F: $F$, F2: $F'$, O: $O$)` only the names it writes otherwise; `hidden: ("B'", "OA'")` the names or distances a card asks for, written "?";
- one call per figure, nothing drawn by yourself (no ray, angle, point or line of your own), no value computed by you: when the description gives a computed value (i2 ≈ 29°, OA' = 12 cm), give the data it comes from and let the function compute it.
