Regarde la leçon et choisis les cartes les plus utiles pour la réviser :
- vocabulaire d'une langue : une carte par mot ou expression, recto dans ma langue, verso dans la langue étudiée ;
- leçon de cours (histoire, sciences, géographie…) : questions / réponses courtes, ou texte à trous pour les phrases à retenir ;
- formules : une carte par formule (recto : ce qu'elle calcule, verso : la formule) ;
- une notion qu'une figure fait comprendre (géométrie, ou toute figure de la leçon) : des cartes avec une figure exacte quand elle aide ;
- schéma avec des légendes : schéma à compléter, une carte par légende ;
- dictée à préparer (un texte ou une liste de mots à savoir écrire) : seulement des cartes de dictée, pour toute la leçon ; pour chaque mot, recto : une courte phrase qui l'utilise, le mot remplacé par « … », verso : le mot seul ; pour un texte, une carte par phrase, recto : « Phrase 1 », « Phrase 2 »…, verso : la phrase exacte, avec sa ponctuation ;
- tableau à savoir par cœur (déclinaison, conjugaison, verbes irréguliers…) : une carte par case, sauf celle d'où vient le mot modèle (sa forme de base) (recto : le mot modèle et les en-têtes de la case, verso : la case, info : la terminaison), ou une par ligne si chaque ligne est un mot différent (recto : le premier élément et, entre parenthèses, les en-têtes des autres colonnes, verso : ces colonnes séparées par des virgules) ; réponse tapée ;
- dates et repères (une frise, des dates à retenir) : une carte par repère, recto : l'événement, verso : sa date, info : le siècle ; avec la carte inverse ;
- propriétés et théorèmes (un encadré « Propriété », « Théorème ») : une carte nom → énoncé complet (« Si …, alors … »), une carte hypothèses → conclusion, la réciproque à part quand la leçon la donne ; info : à quoi elle sert ;
- notions illustrées d'exemples (figures de style, classes ou fonctions grammaticales…) : une carte par exemple de la leçon, recto : une courte question qui dit ce qu'il faut reconnaître, puis l'exemple, verso : la notion, info : sa définition ; jamais d'exemple inventé ;
- texte à apprendre par cœur (poème, récitation, tirade ; pas une dictée) : une carte par vers à partir du deuxième, recto : le titre, le numéro du vers et les deux vers d'avant, verso : le vers, le début d'une strophe dit au recto ; une carte titre → premier vers ; le texte exact ; lu à voix haute ;
Pour chaque partie de la leçon, prends le cas de la liste qui la décrit et suis sa forme à la lettre : autant de cartes qu'il dit, ses rectos et versos, ses cartes en plus ; les questions / réponses seulement pour ce qu'aucun cas ne décrit.
Mélange si la page contient plusieurs de ces choses, sauf une dictée à préparer : elle seule alors.
Dis en une phrase ce que tu as choisi.
